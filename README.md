# Bodega Atypical · prototipo

App web estática (un solo `index.html`) que reemplaza el Excel *Control de bodega*: ventas con factura, plan separe, compras, inventario, productos, clientes y proveedores.

**Datos:** en este prototipo se guardan en el navegador de cada persona (localStorage) y arrancan con los datos de ejemplo del Excel. El botón "Restablecer datos de ejemplo" vuelve al estado inicial.

## Publicar en Vercel
1. Instala Node.js (https://nodejs.org) si no lo tienes.
2. Abre una terminal en esta carpeta y ejecuta: `npx vercel --prod`
3. Inicia sesión cuando lo pida y acepta las opciones por defecto. Al final te da la URL pública.

Sin instalar nada: arrastra esta carpeta a https://app.netlify.com/drop
